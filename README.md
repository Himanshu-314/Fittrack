# FITTRACK 12

Personal 12-week fitness app (PWA): six-day routine with exercise photos, **set-by-set tracking**,
**progression suggestions**, **strength / volume / consistency analytics**, body measurements, cardio,
and a **smart nutrition tracker** (photo, natural-language description, quick add) with calorie, macro,
fibre and mineral targets. Works offline; data stays on your phone; JSON backup & restore.

Files: `index.html`, `app.js` (core), `nutrition.js`, `foods.js` (offline food database + parser),
`sw.js`, `manifest.webmanifest`, `icon.svg`, `icons/`, `assets/` (exercise photos),
`backend/` (optional AI service; deploy separately — never commit API keys).
